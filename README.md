## ▶️ How to Run

### Step 1 — Run Python in Google Colab

Open Google Colab and run:

```python
# Install dependencies
!pip install requests numpy cdsapi netCDF4 flask flask-cors -q

# Clone or upload your project, then:
!python generate_data.py

# With your NASA FIRMS key:
!python generate_data.py --key YOUR_FIRMS_MAP_KEY

# With Copernicus CDS (real GloFAS):
!python generate_data.py --cds-uid YOUR_UID --cds-key YOUR_API_KEY
```

This writes `public/dashboard_data.json` with all processed data.

### Step 2 — Download dashboard_data.json from Colab

In Colab, run:
```python
from google.colab import files
files.download('public/dashboard_data.json')
```

### Step 3 — Commit to GitHub

Upload `public/dashboard_data.json` to your GitHub repo.  
Vercel auto-deploys within 30 seconds.

## 🚀 GitHub + Vercel Deployment

### GitHub (one time only)

1. Go to **github.com** → **+** → **New repository**
2. Name: `cpec-multihazard-ews` → **Public** → **Create repository**
3. Upload all project files by dragging into the repo
4. Make sure `public/dashboard_data.json` is included

### Vercel (one time only)

1. Go to **vercel.com** → sign up with GitHub
2. **Add New → Project** → import `cpec-multihazard-ews`
3. Set **Output Directory** to `public`
4. Click **Deploy**

Your live URL:
```
https://cpec-multihazard-ews.vercel.app
```

### Update workflow (every time you re-run Python)

```
Run generate_data.py in Colab
    → Download public/dashboard_data.json
    → Upload to GitHub repo
    → Vercel auto-deploys (30 seconds)
    → Dashboard shows fresh data
```

## 🔑 API Keys (all free)

### NASA FIRMS (fire hotspots)
1. Register at: https://firms.modaps.eosdis.nasa.gov/api/
2. Get your MAP_KEY
3. Use: `python generate_data.py --key YOUR_MAP_KEY`

### Copernicus CDS (real GloFAS data)
1. Register at: https://cds.climate.copernicus.eu/user/register
2. Get UID + API key from your profile
3. Use: `python generate_data.py --cds-uid YOUR_UID --cds-key YOUR_KEY`
4. Accept dataset terms:
   - https://cds.climate.copernicus.eu/cdsapp#!/dataset/cems-glofas-forecast

### NASA Earthdata (real GPM IMERG)
1. Register at: https://urs.earthdata.nasa.gov/users/new
2. Use: `python generate_data.py --ed-user USERNAME --ed-pass PASSWORD`

**Dashboard works without any keys** — falls back to realistic mock/calibrated data.

## 📊 Dashboard Features

- **Live Operations Centre** — dark tactical theme
- **Scrolling alert ticker** — real-time hazard broadcasts
- **6 animated KPI counters** — fires, rainfall, flood alerts, landslide, population, risk
- **30-minute auto-refresh** — countdown timer shown on map
- **10 interactive map layers** on Pakistan-centred Leaflet map
- **GloFAS 7-day forecast chart** per Indus reach with LTM threshold lines
- **6 analytics tabs** — exposure table, landslide, rainfall, DEM, population, policy brief
- **5 downloadable outputs** — policy brief (.md), exposure CSV, fires/flood/rainfall GeoJSON
- **Python status indicator** — shows whether data is from Colab or live API fallback
